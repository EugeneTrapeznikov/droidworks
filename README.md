# Droidworks

Public tools and extensions for agentic software development.

## Capabilities

| Capability | Description |
| --- | --- |
| [Pi](pi/) | Theme-driven fullscreen selection and guarded installed-package patching for Pi. |
| [TokenJuice + RTK](tokenjuice-rtk/) | Layered Pi Bash-output compaction without double filtering. |

Temporary forks used for upstream contributions live under [droidworks-oss](https://github.com/droidworks-oss).
